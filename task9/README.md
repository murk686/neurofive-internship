## Brand Identity

### Logo
A geometric flow-node mark combined with the Space Grotesk wordmark. Available in 4 variants:
- Primary (light backgrounds)
- Reversed (dark backgrounds)
- On accent (marketing use)
- Icon only (favicon & app icon)

### Color Palette
| Name | Hex | Usage |
|------|-----|-------|
| Midnight | `#0A0F2C` | Primary / Brand |
| Flow Blue | `#4F6EF7` | Accent / CTA |
| Deep Blue | `#2B4AE8` | Hover / Active |
| Cloud | `#EEF1FF` | Light Accent |
| Off White | `#F8F9FB` | Background |

### Typography
- **Display & Headings:** Space Grotesk (700, 600, 500)
- **Body & UI:** Inter (400, 600)
